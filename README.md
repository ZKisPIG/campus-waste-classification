# 校园生活垃圾分类与资源化利用助手

## 项目简介

本项目是《人工智能基础与应用》课程实验作品，围绕校园日常生活中的垃圾分类与资源循环利用，制作了一个简单实用的网页助手。

## 在线体验

**网页访问地址：**

https://zkispig.github.io/campus-waste-classification/

## 主要功能

### 1. 垃圾分类查询
输入常见垃圾名称，即可查询对应的垃圾类别和投放建议。

### 2. 垃圾分类知识
介绍可回收物、有害垃圾、厨余垃圾和其他垃圾四种类别。

### 3. 资源化利用
介绍废纸、废塑料、废金属和厨余垃圾的常见资源化利用方式。

## 技术说明

- HTML：网页结构
- CSS：网页样式
- JavaScript：页面交互功能
- GitHub Pages：网页在线部署

## 运行说明

下载项目中的 `index.html` 文件，使用 Chrome、Edge 等浏览器打开即可运行，无需安装其他软件。

## AI 辅助制作

项目使用 ChatGPT、DeepSeek 等人工智能工具辅助完成选题规划、网页代码生成、内容整理和页面优化。

本作品不接入真实 AI API，垃圾分类查询采用网页内置数据实现。
